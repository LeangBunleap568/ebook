=====================================================
  HOW TO CLONE A LOCAL MYSQL DATABASE VIA TERMINAL
=====================================================

PREREQUISITE:
MySQL Command Path: C:\Program Files\MySQL\MySQL Server 8.0\bin
Port: 3309

-----------------------------------------------------
STEP 1: Log into MySQL & Create the Target Database
-----------------------------------------------------
Run in PowerShell:
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -P 3309 -p

Inside MySQL prompt (mysql>):
CREATE DATABASE ebook_clone;
EXIT;

-----------------------------------------------------
STEP 2: Clone Directly (No Intermediate File Saved)
-----------------------------------------------------
Pipe the source database directly into the new target database:

& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe" -u root -P 3309 -p ebook | & "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -P 3309 -p ebook_clone

(Note: Enter your password twice when prompted)

-----------------------------------------------------
STEP 3: Alternative - Clone Using a Temporary SQL File
-----------------------------------------------------
Export source DB to a file:
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe" -u root -P 3309 -p ebook > backup.sql

Import into target DB:
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -P 3309 -p ebook_clone < backup.sql

-----------------------------------------------------
STEP 4: Verify the Cloned Database
-----------------------------------------------------
Log back into MySQL:
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -P 3309 -p

Check tables:
USE ebook_clone;
SHOW TABLES;
"@
